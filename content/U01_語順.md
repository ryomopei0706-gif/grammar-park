## キー文
- I like coffee.｜コーヒーが好き。
- I play tennis.｜テニスをする。
- We need water.｜水が要る。

## ブロック図
[I|subj] [like|verb] [coffee.|obj]
[私は|0] [コーヒーが|2] [好き|1]

## 出会う
### 英語は「だれが → どうする → なにを」
日本語は「私は コーヒーが 好き」と、動詞が最後に来る。英語は「I like coffee.」と、動詞を2番目に言う。この順番さえ守れば、単語を入れ替えるだけで文が作れる。
> I like coffee.｜コーヒーが好き。
### 「なにを」は無くてもいい
「走る」「泳ぐ」のように、相手がいらない動作は2語で終わる。文の先頭は必ず「だれが」。
> I swim.｜泳ぐ。
### 文の最初は大文字、最後はピリオド
書くときのルール。話すときは気にしなくていいが、アプリの問題では付ける。
> We need water.｜水が要る。

## 気づく
- 比較｜コーヒーが好き｜I like coffee.｜I coffee like.｜a｜動詞 like は「だれが」のすぐ後ろ
- 比較｜テニスをする｜Tennis play I.｜I play tennis.｜b｜文の先頭は「だれが」の I
- 誤り｜I water need.｜water→need｜動詞 need を先に、water は最後
- 比較｜泳ぐ｜I swim.｜Swim I.｜a｜「なにを」が無くても、順番は「だれが→どうする」
- 誤り｜Like I music.｜Like→I｜先頭は「だれが」。I like music. が正しい

## 練習
- 並べ替え｜コーヒーが好き。｜I like coffee.｜ダミー: likes
- 並べ替え｜テニスをする。｜I play tennis.｜ダミー: play, to
- 並べ替え｜水が要る。｜We need water.｜ダミー: needs
- 並べ替え｜音楽が好き。｜I like music.｜ダミー: is
- 穴埋め｜I ___ coffee.｜like / coffee / I｜like｜「だれが」の後ろは「どうする」
- 穴埋め｜We ___ water.｜water / need / we｜need｜need（要る）は動詞
- 4択｜「英語を勉強する」は？｜I study English. / I English study. / Study I English. / English I study.｜I study English.｜だれが → どうする → なにを
- 書き換え｜I like coffee.｜coffee を tea に｜I like tea.
- 並べ替え｜泳ぐ。｜I swim.｜ダミー: swim, am
- 誤り｜I English speak.｜English→speak｜動詞 speak を先に

## 使う
### 瞬間英作文
- ★ コーヒーが好き。｜I like coffee.
- ★ テニスをする。｜I play tennis.｜別解: I play tennis every week.
- ★ 水が要る。｜We need water.｜別解: I need water.
- ★ 英語を勉強する。｜I study English.
- ★ 音楽が好き。｜I like music.
- 泳ぐ。｜I swim.
- 紅茶が好き。｜I like tea.
- 英語を話す。｜I speak English.
- 時間が要る。｜We need time.｜別解: I need time.
- 映画が好き。｜I like movies.｜別解: I like films.
### マイ例文
お題: あなたが「好きなもの」を1つ、「I like …」で
ヒント: I like … / We like … / coffee, music, movies, Disney
例: I like Disney.｜ディズニーが好き。
例: I like old houses.｜古い家が好き。

## 単語
- like｜〜が好き｜v｜I like coffee.｜コーヒーが好き。
- play｜（スポーツを）する・遊ぶ｜v｜I play tennis.｜テニスをする。
- need｜〜が要る｜v｜We need water.｜水が要る。
- study｜勉強する｜v｜I study English.｜英語を勉強する。
- speak｜話す｜v｜I speak English.｜英語を話す。
- swim｜泳ぐ｜v｜I swim.｜泳ぐ。
- coffee｜コーヒー｜n｜I like coffee.｜コーヒーが好き。
- tea｜紅茶・お茶｜n｜I like tea.｜紅茶が好き。
- water｜水｜n｜We need water.｜水が要る。
- tennis｜テニス｜n｜I play tennis.｜テニスをする。
- music｜音楽｜n｜I like music.｜音楽が好き。
- movie｜映画｜n｜I like movies.｜映画が好き。
- English｜英語｜n｜I study English.｜英語を勉強する。
- time｜時間｜n｜We need time.｜時間が要る。
- I｜私は｜pron｜I like coffee.｜コーヒーが好き。
- we｜私たちは｜pron｜We need water.｜水が要る。
